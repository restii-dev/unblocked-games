# Unblocked Games

Simple clean hub. Click a game → it opens in a full-page iframe.

**Live:** https://restii-dev.github.io/unblocked-games/

## For Google Sites
1. Enable GitHub Pages on this repo (Settings → Pages → Deploy from main).
2. In Google Sites, insert → Embed → by URL → paste the live link above.

Or just open the GitHub Pages link directly.

Games include a few public ones that usually work in iframes plus your own restii-dev HTML projects (RustikOP, RustOS, Overt, Realistic Mario variants, etc.).

If a game is blocked by the school filter, the iframe will just fail to load that one title.
